# 3D source models (not served with the game)
Rigged Meshy GLBs on the shared humanoid skeleton, plus motion libraries. Used by tools/render3d on main.
- villager_m_anim.glb / villager_m_anim2.glb / combat_anim.glb: male villager rig carrying all motion clips
- *_rig.glb: rigged characters (clips are borrowed via clipsUrl)
- refs/: reference images
